# Autonomous Benchmark Parameters (Efficiency protocol: four effort levels, every run counts)

Benchmark: strategy-planning/last-rampart
Protocol: Efficiency protocol (see PROTOCOL.md; each row's protocol_version is in telemetry.json)
Intervention: Zero human-in-the-loop
Filesystem Isolation: macOS Seatbelt (`baseline/sandbox.sb`) blocking `/Volumes`, repository roots, sibling `/private/tmp` runs, and personal host folders (`~/Desktop`, `~/Documents`, `~/Downloads`, `~/Projects`, `~/Developer`).
Environment Policy: Allowlisted child environment (`XDG_*` and `TMPDIR` scoped to `/private/tmp/pcd-sbx-<model>-<id>`), parent-owned telemetry capture outside child writable `RUN_ROOT`.

Generated by `baseline/gen_parameters.py` from `telemetry.json` and the orchestrator's `build_command()`.
Only the reasoning-effort value changes between rows. Harness versions below are the versions recorded
for each published run.
